# Portfolio content: what to share

The easiest way to start: **paste your CV, or rough notes about yourself.** Either is enough to get going, in any format. You don't need to fill anything in neatly; the rest can be sorted out together. Nothing here is mandatory.

## Fastest path (just these)
If you want to keep it short, the CV plus these four answers is plenty. Skip any you don't care about and good defaults are used.

1. **Who is this mainly for?** recruiters / clients / peers / a mix
2. **The one thing a visitor should do?** reach out / see my work / get to know me
3. **Keep it about you even if you change jobs?** yes / fine to feature where I work
4. **Any look you're drawn to?** a colour, a site you admire, or "you pick"

The rest below is optional detail, only if you feel like it.
